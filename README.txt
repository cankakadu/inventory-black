Inventory Blacklist - Fabric Mod (Minecraft 1.21.1)
===================================================

Anleitung zum Bauen (.jar erstellen):
1. Stelle sicher, dass Java 21 JDK auf deinem System installiert ist.
2. Öffne den Terminal/Eingabeaufforderung in diesem Ordner.
3. Führe folgenden Befehl aus:
   - Windows: gradle build (oder gradlew build, wenn Wrapper installiert)
   - Linux/Mac: ./gradlew build
4. Nach dem Build befindet sich die fertige Mod .jar Datei unter:
   build/libs/inventoryblacklist-1.0.0.jar

Installation im Spiel:
1. Installiere Fabric Loader 1.21.1.
2. Kopiere die generierte .jar Datei sowie Fabric API in deinen .minecraft/mods Ordner.
3. Starte das Spiel und öffne das Menü mit der Taste 'B'.
